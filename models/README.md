# Models

Place `.tflite` files here. The pretrained files are:

- `mobilenet_v2_1.0_224_quant.tflite`
- `labels.txt`

If they are not supplied by your course folder, download:

```text
https://storage.googleapis.com/download.tensorflow.org/models/tflite_11_05_08/mobilenet_v2_1.0_224_quant.tgz
https://storage.googleapis.com/download.tensorflow.org/data/ImageNetLabels.txt
```

Rename `ImageNetLabels.txt` to `labels.txt`.
